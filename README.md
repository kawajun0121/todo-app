# 個人TODO・プロジェクト管理アプリ

インストール不要・ビルド不要で動く、個人専用のTODO・プロジェクト管理Webアプリです。
PWA（インストール可能なWebアプリ）にも対応しており、Windowsのデスクトップアプリ、iPhoneのホーム画面アプリとしても使えます。

## 使い方（ブラウザでそのまま開く場合）

1. [index.html](index.html) をブラウザ（Chrome / Edge など）でダブルクリックして開くだけです。
2. データはこのパソコンのブラウザの中（localStorage）に保存されます。ブラウザを閉じても消えません。
3. 別のパソコン・スマートフォンとはまだ同期されません（今後の拡張予定）。この方法では、PCとiPhoneはそれぞれ別のデータになります。

## アプリとしてインストールする（Windows / iPhone）

インストールするには、`index.html` をダブルクリックする代わりに、ホスティングされたURL（例: `https://ユーザー名.github.io/リポジトリ名/`）からアクセスします。`file://`で直接開いた場合はインストールできません。

### Windows（Edge）

1. ホスティングされたURLをEdgeで開く
2. アドレスバー右側の「アプリのインストール」アイコン（または右上の「…」→「アプリ」→「このサイトをアプリとしてインストール」）をクリック
3. デスクトップ・スタートメニューにアイコンが追加され、ウィンドウ独立のアプリとして起動できるようになる

### iPhone（Safari）

1. ホスティングされたURLをSafariで開く（Chrome等では「ホーム画面に追加」がPWAとして動作しないため、必ずSafariを使う）
2. 共有ボタン（□に↑）をタップ → 「ホーム画面に追加」を選択
3. ホーム画面にアイコンが追加され、タップするとブラウザのUIなしで全画面のアプリとして起動する

### 注意点

- WindowsとiPhoneは別々にインストールするため、データは同期されません（それぞれ独立したlocalStorageを持ちます）。同期には将来クラウド同期機能の追加が必要です。
- アプリ本体（HTML/CSS/JS）はサービスワーカー（`sw.js`）でキャッシュされ、オフラインでも起動・利用できます。ファイルを更新した場合は `sw.js` の `CACHE_NAME` のバージョンを上げてください。

### バックアップについて

データはブラウザ内に保存されているため、ブラウザの「閲覧履歴の削除」で消える場合があります。
大事なデータがある場合は、定期的にブラウザの開発者ツール（F12）→ Application → Local Storage の内容をコピーしておくと安心です（将来クラウド同期を追加すればこの手間はなくなります）。

## フォルダ構成

```
index.html            アプリ本体（これを開く）
manifest.json          PWA設定（アプリ名・アイコン・配色）
sw.js                   サービスワーカー（オフラインキャッシュ）
icons/                  アプリアイコン各サイズ
src/
  pwa.js               サービスワーカーの登録
  types/typedefs.js   データ構造の説明（JSDoc）
  storage/            データの保存・読み込み（localStorage）
  store/               データの管理（プロジェクト・TODO・テンプレート・履歴・画面状態）
  logic/               計算ロジック（進捗率・スマート一覧・待機期限・繰り返し・検索）
  render/               画面の見た目（HTML組み立て）
  styles/               CSS（デザイン）
tests/
  logic.test.html      ロジック層の自動テスト（ブラウザで開くだけで実行される）
```

## テストの実行方法

[tests/logic.test.html](tests/logic.test.html) をブラウザで開くと、進捗計算やスマート一覧の抽出条件などが正しく動くか自動でチェックされ、結果が画面に表示されます。

## Claude Codeへ機能追加を頼むときのコツ

このアプリは「役割ごとにファイルを分ける」構成にしてあります。頼むときに次のように場所を伝えると、変更範囲を絞りやすくなります。

- **TODOやプロジェクトの項目を増やしたい** → 「`src/types/typedefs.js` の Todo に◯◯という項目を追加して」
- **スマート一覧の条件を変えたい・増やしたい** → 「`src/logic/smartLists.js` に条件を追加して」
- **画面の見た目を変えたい** → 「`src/render/` の該当ファイルと `src/styles/components.css` を調整して」
- **保存先をクラウドに変えたい（将来）** → 「`src/storage/storageAdapter.js` を差し替えて」

「今のままで動かなくなっていないか、`tests/logic.test.html` で確認して」と付け加えると安全です。
