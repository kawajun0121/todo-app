# 個人TODO・プロジェクト管理アプリ

インストール不要・ビルド不要で動く、個人専用のTODO・プロジェクト管理Webアプリです。
PWA（インストール可能なWebアプリ）にも対応しており、Windowsのデスクトップアプリ、iPhoneのホーム画面アプリとしても使えます。
Firebase（無料のクラウドサービス）を使ってログインすると、PCとiPhoneでデータが同期されます。

## 使い方（ブラウザでそのまま開く場合）

1. [index.html](index.html) をブラウザ（Chrome / Edge など）でダブルクリックして開くだけです。
2. 初回はログイン画面が表示されます。メールアドレスとパスワードで「新規登録」してください（同じアカウントでログインした端末同士のデータが同期されます）。
3. データはこのパソコンのブラウザの中（localStorage）にも保存されるため、オフラインでも使えます。ログイン中は自動的にクラウド（Firestore）とも同期されます。

## アプリとしてインストールする（Windows / iPhone）

インストールするには、`index.html` をダブルクリックする代わりに、ホスティングされたURL（例: `https://ユーザー名.github.io/リポジトリ名/`）からアクセスします。`file://`で直接開いた場合はインストールできません。

### Windows（Edge）

1. ホスティングされたURLをEdgeで開く
2. アドレスバー右側の「アプリのインストール」アイコン（または右上の「…」→「アプリ」→「このサイトをアプリとしてインストール」）をクリック
3. デスクトップ・スタートメニューにアイコンが追加され、ウィンドウ独立のアプリとして起動できるようになる

### iPhone（Safari）

1. ホスティングされたURLをSafariで開く（Chrome等では「ホーム画面に追加」がPWAとして動作しないため、必ずSafariを使う）
2. 共有ボタン（□に↑）をタップ → 「ホーム画面に追加」を選択
3. ホーム画面にアイコンが追加され、タップするとブラウザのUIなしで全画面のアプリとして起動する

### 注意点

- Windows・iPhoneのどちらも、**同じメールアドレスでログイン**すればデータが同期されます（下記「PC/iPhoneでのデータ同期」参照）。
- アプリ本体（HTML/CSS/JS）はサービスワーカー（`sw.js`）でキャッシュされ、オフラインでも起動・利用できます。ファイルを更新した場合は `sw.js` の `CACHE_NAME` のバージョンを上げてください。

## PC/iPhoneでのデータ同期

Firebase（Google の無料のクラウドサービス）を使って、ログインしている端末同士でTODO・プロジェクト・テンプレート・履歴を同期します。

### 新しい端末を追加する

1. その端末のブラウザ（Windowsは Edge、iPhoneは Safari）でアプリのURLを開く
2. ログイン画面で、**既に使っているのと同じメールアドレス・パスワード**でログイン（「ログイン」タブ。新規登録ではない）
3. しばらくすると、他の端末で登録済みのデータが表示される

### 同期の仕組みと制限

- Firestore（Firebaseのデータベース）上に、ログインしているアカウント（`users/{自分のuid}/data/…`）専用のデータを保存し、端末間で読み書きを行っています。他人のデータにはアクセスできません（Firestoreのセキュリティルールで制限）。
- ローカル（localStorage）にも常に保存されるため、オフラインでも今まで通り使えます。オンラインに戻ると自動的に同期されます。
- **同時編集の制限**: 2台をほぼ同時にオフラインで編集すると、更新日時が新しい方（後から同期した方）が優先されます。片方の変更が上書きされる場合があります。
- **削除の制限**: 一方の端末で削除した項目が、同期のタイミングによっては復活することがあります（簡易な同期の仕組みのため）。頻繁に同時編集しない個人利用を想定しています。

### ログアウト・アカウント切り替え

サイドバー下部にログイン中のメールアドレスと「ログアウト」ボタンがあります。ログアウトしてもこの端末のローカルデータは消えません。

### Firebase設定を変更したい場合

`src/firebaseConfig.js` にFirebaseプロジェクトの設定値があります。別のFirebaseプロジェクトに変える場合はここを書き換えてください（Firebase Consoleの「プロジェクトの設定」→「マイアプリ」から取得できます）。Firestoreのセキュリティルールは以下にしてあります（Firebase Console → Firestore Database → ルール）。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/data/{document} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

### バックアップについて

同期を使っていればFirestore側にもデータが残りますが、念のためブラウザの開発者ツール（F12）→ Application → Local Storage の内容を定期的にコピーしておくとより安心です。

## フォルダ構成

```
index.html            アプリ本体（これを開く）
manifest.json          PWA設定（アプリ名・アイコン・配色）
sw.js                   サービスワーカー（オフラインキャッシュ）
icons/                  アプリアイコン各サイズ
src/
  firebaseConfig.js    Firebaseプロジェクトの設定値
  pwa.js               サービスワーカーの登録
  sync/                ログイン画面・クラウド同期（Firebase）
  types/typedefs.js   データ構造の説明（JSDoc）
  storage/            データの保存・読み込み（localStorage）
  store/               データの管理（プロジェクト・TODO・テンプレート・履歴・画面状態）
  logic/               計算ロジック（進捗率・スマート一覧・待機期限・繰り返し・検索）
  render/               画面の見た目（HTML組み立て）
  styles/               CSS（デザイン）
tests/
  logic.test.html      ロジック層の自動テスト（ブラウザで開くだけで実行される）
```

## テストの実行方法

[tests/logic.test.html](tests/logic.test.html) をブラウザで開くと、進捗計算やスマート一覧の抽出条件などが正しく動くか自動でチェックされ、結果が画面に表示されます。

## Claude Codeへ機能追加を頼むときのコツ

このアプリは「役割ごとにファイルを分ける」構成にしてあります。頼むときに次のように場所を伝えると、変更範囲を絞りやすくなります。

- **TODOやプロジェクトの項目を増やしたい** → 「`src/types/typedefs.js` の Todo に◯◯という項目を追加して」
- **スマート一覧の条件を変えたい・増やしたい** → 「`src/logic/smartLists.js` に条件を追加して」
- **画面の見た目を変えたい** → 「`src/render/` の該当ファイルと `src/styles/components.css` を調整して」
- **ログイン画面の見た目・項目を変えたい** → 「`src/sync/authUI.js` を調整して」
- **同期の対象を増やしたい・挙動を変えたい** → 「`src/sync/cloudSync.js` を調整して」

「今のままで動かなくなっていないか、`tests/logic.test.html` で確認して」と付け加えると安全です。
